# Sample data

`sample_prices.csv` is a **synthetic** dataset. It is generated by
[`src/sample_data.py`](../src/sample_data.py) with a fixed random seed, so it is
fully reproducible and the app works without an internet connection.

**It is not market data.** Every column has a `SYN_` prefix so it cannot be
mistaken for a real security, and no result computed from it says anything
about real markets.

| Column | Stylised behaviour |
|---|---|
| `SYN_MARKET` | Broad equity index, used as the default benchmark |
| `SYN_US_EQUITY` | Large-cap equity, beta ≈ 1 |
| `SYN_TECH_GROWTH` | High-beta equity, higher volatility |
| `SYN_INTL_EQUITY` | Equity, beta ≈ 0.85, **no price on 26 December** (local holiday) |
| `SYN_EM_EQUITY` | Equity, beta ≈ 1.1, **listed on 2017-03-01** (no earlier prices) |
| `SYN_TREASURY` | Government bond, slightly negative equity beta |
| `SYN_CORP_BOND` | Credit, mild equity exposure |
| `SYN_GOLD` | Low correlation to equities |
| `SYN_REIT` | Real estate, equity and rate sensitivity |

- **Calendar:** weekdays from 2015-01-02 to 2024-12-31. There is no exchange
  holiday calendar.
- **Model:** a two-factor (equity, rates) log-return model with Student-t(5)
  shocks. It contains stylised stress regimes, including a sharp crash with a
  rebound and a prolonged bear market in which bonds and equities fall together.
  These regimes are illustrative and do not reproduce actual market history.
- **Prices:** start at 100 and are treated as adjusted closes (total-return
  index levels).
- **Deliberate gaps:** the gaps in `SYN_INTL_EQUITY` and `SYN_EM_EQUITY`
  demonstrate the missing-data handling. They are reported by the app, never
  silently filled.

Regenerate the file with:

```bash
python -m src.sample_data
```

`tests/test_data_loader.py` checks that the committed file matches the generator.
